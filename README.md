# Product Roadmap

## Vision

一个本地优先的长期计划系统

## Why

大多数任务工具适合记录短期事项，
但长期项目往往需要：

- 持续推进
- 自动重复
- 复杂依赖
- 可追踪历史
- 长时间演进

这个项目希望提供一种更适合长期执行的工作流。


---

## Current Focus

- 增强计划推理引擎
- 简化高级触发器创建流程
- 提高长期计划的自动化能力
